Bulk assign, never bulk approve. Assignment is reversible and administrative, so it batches safely. A decision is irreversible, attaches to a named person, and requires looking at evidence — so “Approve selected” exists only as a disabled control whose tooltip explains the rule. Removing it entirely would leave reviewers hunting for a feature that is deliberately absent.
No face appears in the queue. The preview column is a veiled placeholder. A reviewer scrolling 200 rows has no operational need to see faces, and an unveiled queue is a bulk disclosure waiting to be screenshotted.
