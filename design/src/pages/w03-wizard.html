Continue is never blocked by a later step's problem. The user can move forward with session 2 unresolved — the running “Still to resolve” panel carries the debt, and only submit is gated. Blocking navigation on validation is how a 24-field form becomes a spreadsheet instead.
Organisation-configured values are shown, not hidden. A campaign admin who cannot see the geofence radius or the attribution window will design sessions that quietly violate them. Showing the values as a read-only panel — clearly labelled as configuration — prevents the whole class of problem.
